# Technical Strengths — GitHub profile

Upload `technical-strengths.svg` into your **Leuben** profile repository, ideally under `assets/`.
Then add the following Markdown to your profile README (`Leuben/README.md`):

```md
## Technical Strengths

![Technical strengths — self-assessed skills](assets/technical-strengths.svg)
```

If you upload the SVG into the repository root instead, use `![Technical strengths](technical-strengths.svg)`.

The percentages represent personal self-assessments, not verified GitHub metrics.
